# 强化学习

- 预训练阶段：让模型学习语言，建立对世界和语言的认知 （通识）
- 微调阶段：使模型学会指令跟随，根据问题回答 （考试前突击）
- **强化学习阶段**：让模型与人类偏好对齐，符合世界观 ；目标导向的策略生成（KPI导向生成）
- RAG 为模型外挂知识库，agent 为其外挂工具。

与SFT的区别：

- SFT 依赖数据标注的质量和覆盖性，泛化性有限，需覆盖场景内所有数据才能达到效果；存在机械模仿和创造性不足的问题，难以处理多目标、多答案的情况；无法进行拒绝，模型只能知道下一个 TOKEN 是什么，不知道不应该是什么 （如何回答）
- RLHF 通过奖励模型将人类偏好融入其中，能覆盖不同 query，与人类偏好对齐；可对所有正确答案打高分，随机生成答案，处理多目标、多答案问题；能拒绝有害回答，解决实际生产场景中的 Badcase。（如何回答得更好）
